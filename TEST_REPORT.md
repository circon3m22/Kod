## Разрешения

Встроенное проверочное окно получало настоящий viewport каждого размера. Ожидалось завершение пересчёта data-scale и data-rotation.

| Окно | Поворот | Сцена |
| --- | ---: | --- |
| 1920×1080 | 0° | 1920×1080 |
| 1366×768 | 0° | 1365,33×768 |
| 390×844 | 90° | 390×693,33 |
| 430×932 | 90° | 430×764,44 |
| 844×390 | 0° | 693,33×390 |
| 932×430 | 0° | 764,44×430 |

Поля сохраняют 16:9 без обрезки. В 390×844 проверены переходы через команды и этапы к карте, раскрытие ответа, начисление в круглом меню и сопоставление. Обнаруженный сдвиг на 8 пикселей при фокусировке во время анимации исправлен заменой overflow:hidden на overflow:clip у сцены и основного контейнера. После исправления scrollLeft/scrollTop равны 0/0 и после раскрытия ответа. Ориентация теперь определяется по layout viewport, чтобы появление экранной клавиатуры не меняло визуальный поворот.
