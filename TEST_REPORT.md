- Семь сцен по 4 секунды, статичная афиша между циклами — 4 секунды. Каждая пара содержит только части соответствующей буквы.

- Быстрые случайные смены фотографий, разлёты и бегущие блики удалены. Входящая сцена накладывается вместе с белым фоном, чтобы при переходе не возникало вспышки от суммирования прозрачностей. Фотографии конечной афиши возвращаются до окончания сборки.

## Разрешения

Встроенное проверочное окно получало настоящий viewport каждого размера. Ожидалось завершение пересчёта data-scale и data-rotation.

| Окно | Поворот | Сцена |
| --- | ---: | --- |
| 1920×1080 | 0° | 1920×1080 |
| 1366×768 | 0° | 1365,33×768 |
| 390×844 | 90° | 390×693,33 |
| 430×932 | 90° | 430×764,44 |
| 844×390 | 0° | 693,33×390 |
| 932×430 | 0° | 764,44×430 |

Поля сохраняют 16:9 без обрезки. В 390×844 проверены переходы через команды и этапы к карте, раскрытие ответа, начисление в круглом меню и сопоставление. Обнаруженный сдвиг на 8 пикселей при фокусировке во время анимации исправлен заменой overflow:hidden на overflow:clip у сцены и основного контейнера. После исправления scrollLeft/scrollTop равны 0/0 и после раскрытия ответа. Ориентация теперь определяется по layout viewport, чтобы появление экранной клавиатуры не меняло визуальный поворот.

## Важные пределы

Компактное меню видно на текущем экране. При зеркалировании оно тоже попадёт на проектор. Полностью незаметное начисление реализовано клавишами без открытия меню; отдельного синхронизированного телефонного пульта нет.

Физические iPhone/Safari, Dynamic Island, проектор и USB-носитель недоступны для проверки. File:// запрещён политикой удалённого тестового браузера, поэтому прямой запуск с флешки здесь не подтверждён. Приложение не использует сетевые зависимости и сервер. Перед мероприятием нужен пробный запуск index.html на целевом компьютере.

При первоначальном тестировании Fullscreen API в тестовом браузере был запрещён, отказ обрабатывается. Успешный системный полный экран и Screen Orientation API на устройстве не подтверждены. Файловый диалог импорта в инструменте проверки зависал; экспорт JSON и восстановление через резервный текстовый импорт были проверены. Эти механизмы в переделке не изменялись.

Скриншоты текущего вида: screenshots/home.jpg, screenshots/board.jpg, screenshots/question.jpg. Для повторения проверки размеров откройте tests/viewport-check.html.
