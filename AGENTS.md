# Культурный код — инструкции для продолжения

Это готовый автономный квиз, а не заготовка.

Текущая редакция: 30 вопросов в шести категориях. По прямому запросу пользователя видеокатегория заменена пятью фотозаданиями «Кадры прошлого», добавлена категория «Что было раньше?». Эти десять новых заданий разрешены пользователем; их условия, источники и критерии зачёта описаны в NEW_ROUNDS.md. Исходные видеовопросы сохранены в source/replaced-video-questions.json. Сначала прочитай README.md, CONTENT_AUDIT.md, QUESTION_REVIEW.md и TEST_REPORT.md.

## Обязательные свойства
- Запуск непосредственным открытием index.html без интернета, сервера и сборки. Не добавляй обязательный fetch локального JSON или CDN.
- Сцена 1920×1080, масштабирование с сохранением 16:9. На вертикальных телефонах визуальный CSS-поворот rotate(90deg).
- Нейтральный минималистичный интерфейс без зелёного и акцентных цветов, простые скруглённые плашки. Изображения показываются в исходном цвете; подлинные ч/б остаются ч/б, без искусственного раскрашивания.
- Главная — живая афиша 4:3: отдельный HTML-текст и SVG-слово КОД из 9 фотосекций, девять разных исторических изображений Руси, войн, Российской империи и СССР из assets/cover-eras; для Руси — явно атрибутированные репродукции картин. О строго круглая; секции вырезаны по цельным силуэтам букв. Данные геометрии — cover-art.js. При нажатии текст затухает, карта сразу плавно исчезает за 380 мс, КОД целиком приближается через центр О, затем карточки этапов плавно появляются слева направо (шаг 120 мс); без растра афиши, генерации и видимых кнопок. Команды редактируются через круг. Сохрани assets/design/cover-mosaic-v1.png и design/cultural-code-poster-4x3.png.
- Сохраняй исходные формулировки вопросов с документированными точечными исправлениями. Не придумывай вопросы, ответы и недостающие видео. Недоступные задания остаются заблокированными.
- Цифра выбирает команду для текущего задания; повторные нажатия не начисляют очки. Последний выбор засчитывается один раз при завершении задания/переходе дальше. Раскрытие ответа не начисляет баллы. Сохрани защиту повторного начисления после повторного открытия.
- Выбранный номер кратко появляется с анимацией в нижнем круге. Цифры таймера меняются прокруткой отдельных разрядов.
- Данные отделены в quiz-data.js. Оригиналы находятся в source/, происхождение и ограничения описаны в CONTENT_AUDIT.md.

## Проверки после значимых изменений
python3 tests/check-content.py
node tests/check-state.cjs
node tests/check-scoring.cjs
node --check app.js

Не публикуй изменения автоматически без указания пользователя. Не изменяй существующий размещённый сайт при работе только с этим репозиторием.

- Этапы — четыре высокие карточки в одном горизонтальном ряду, без номеров, стрелок и подзаголовков. Снизу внутри карточек — локальные цветные предметные иллюстрации с прозрачным фоном (assets/stage-objects). После первых трёх — промежуточные итоги, после капитанов — меню этапов. Финальные результаты открываются через круг, отдельного этапа результатов нет.

- Типографика: Onest Medium 500 для названия и заголовков, Onest Regular 400 для основного текста. Шрифт хранится локально в assets/fonts/Onest-Variable.ttf, лицензия — Onest-OFL.txt. CodeSymbols оставляет локальный DejaVu для стрелок и значков; не добавляй CDN.

- Компактное меню из круга: только названия всех команд и четыре SVG-иконки — домой (этапы), заставка (афиша), отмена последнего начисления, три точки (полная панель). Без номеров, стоимости, счёта, подписей и стрелок. Длинные пояснения остаются только для скринридера. Панель раскрывается из точной области круглой кнопки 64×64 и сворачивается в неё; текст не масштабируется. Закрытие по Escape/нажатию снаружи, обратный переход при быстром повторном открытии и уменьшение движения должны работать. Вторичные инструменты — в полной панели. Источники фото открываются через полную панель → Настройки. Картинки ответов не должны появляться на вопросе, кроме изображений событий хронологии; метаданные и атрибуция — source/answer-image-sources.json.

- Активная отдельная афиша: design/cultural-code-poster-kod-4x3.svg, PNG 3200×2400 и PDF 400×300 мм, строго 4:3. Слово КОД собрано по тем же силуэтам из 9 неповторяющихся фотографий. Текст события: 2 ноября 18:30; «Вектор», ул. Фрунзе, 60. Исходник текущей компоновки — scripts/build-cover-art.py; прежняя A3-афиша и её скрипт сохранены. Старую афишу не удалять.

- Изменения GitHub оформлять обычным Git: отдельная ветка → commit → git push → PR. Пользователь предпочитает этот процесс загрузке через API blob. Слияние и публикация уже разрешены в переписке; не запрашивать повторное подтверждение.

- «Что было раньше?» — 16 событий в 5 вопросах, каждое со своей карточкой и картинкой. На вопросе исходный порядок букв, без дат на карточках. При раскрытии карточки плавно выстраиваются слева направо по датам и показывают годы; для одного 1961 года дополнительно день/месяц. Факты и критерии зачёта не менять. Источники: source/chronology-card-sources.json. Проверка: node tests/check-chronology-browser.cjs.
- Атрибуцию новых фотосекций сохранять в credits.html, метаданных SVG/PNG/PDF и design/cultural-code-poster-kod-4x3-credits.txt. Экспорт: python3 scripts/build-cover-art.py --export.

- Фон живой и печатной афиши — светлый векторный силуэт assets/design/poster-russia-silhouette.svg, без подписей и внутренних границ, точно в пределах листа 4:3. Выбранный пользователем контур включает Крым и четыре заявленные Россией области; источник, автор, лицензия и описание контура — source/poster-background-source.json. Акварельный фон отменён, его исходный файл сохранён.

- На заставке фото непрерывно и независимо смещаются внутри неподвижных масок букв (циклы 24–32 с, запас 10%). При начале приближения движение замораживается; ожидание завершения перехода исключает бесконечные циклы. Уменьшение движения отключает параллакс. Карта плавно исчезает сразу при нажатии за 380 мс.

- Карта на заставке мягко переливается: белый диагональный блик проходит внутри исходной SVG-маски за 22 с; геометрия и серая палитра сохраняются. Блик и основной силуэт исчезают одновременно за 380 мс. При уменьшении движения блик скрыт. Печатные файлы статичны.
