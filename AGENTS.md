# Культурный код — действующая редакция

Актуальные прямые инструкции пользователя: ответы на бланках; 15 новых вопросов разминки и шесть существующих категорий по 10 вопросов. Новые вопросы явно разрешены. Исходные 30 основных формулировок сохраняются; значения и порядок изменены. Предыдущая редакция — source/pre-paper-quiz-data.json.

- Запуск index.html через file:// без сборки, обязательного fetch, CDN и сервера. Данные — quiz-data.js, локальный Onest, символы DejaVu. Сцена 1920×1080, масштабирование 16:9, CSS-поворот на вертикальном телефоне.
- Вопрос появляется с остановленным 30-секундным таймером. Клик запускает его; по нулю — следующий вопрос, опять с остановленным таймером. После всех вопросов — автоматически 30 секунд на сдачу бланков, затем все ответы по порядку. Последний ответ разминки → промежуточные результаты; основного блока → заставка; после всех семи → статистика. Цифры в бумажном режиме не начисляют баллы.
- Ручные баллы имеют roundId для таблицы статистики; общий счёт/корректировки — отдельно. Отмена исключает начисление из суммы блока. Старые счёт, история и taskKey сохраняются; legacyValue сохраняет прежнюю стоимость для старых сохранений. Не вычислять количество верных ответов из суммы баллов.
- При уходе с вопроса бумажный таймер приостанавливается; блок возобновляется с сохранённой позиции. При перезагрузке сначала заставка и приостановленный таймер. Нельзя допустить переход от старого таймера на другом экране.
- Основная навигация: две карточки этапов; далее шесть высоких карточек блоков в одном горизонтальном ряду, изображения снизу. Необязательные творческий этап и капитаны доступны только из подробного меню.
- Все 75 вопросов и ответов имеют изображения. Не показывать отдельные подписи к фото. Alt и атрибуция сохраняются. Не показывать ответные фото на вопросе, если они раскрывают ответ. У событий хронологии остаются содержательные названия карточек. Все 31 событие в 10 вопросах имеют разные изображения внутри своего вопроса; ответ выстраивает их по датам слева направо с годами, для событий одного года — днями и месяцами.
- Минималистичный белый/серый интерфейс, округлые формы. Цветные оригиналы остаются цветными; архивные ч/б не раскрашивать. Новые источники и лицензии — source/paper-image-sources.json и credits.html. Факты/критерии — source/paper-round-content.json. Сборка — scripts/build-paper-rounds.py; печатные бланки и ключ — scripts/build-paper-printables.py.
- Живая афиша 4:3 вручную собрана из HTML и SVG, не растр. Девять неповторяющихся фотосекций в округлых цельных буквах КОД; круглая О. Геометрия cover-art.js. Onest Medium/Regular. Фотографии независимо и непрерывно смещаются 24–32 с под масками; при переходе замирают. Карта с бликом (22 с) исчезает сразу за 380 мс, КОД приближается целиком через центр О (10.5×, 1.28 с). Этапы появляются слева направо с шагом 120 мс. Уменьшение движения отключает анимации. Ожидание перехода не включает бесконечные циклы; сохранён обход Chromium pending startTime.
- Фон — assets/design/poster-russia-silhouette.svg; геометрия, пропорции, светлая заливка и происхождение — source/poster-background-source.json. Печатная афиша design/cultural-code-poster-kod-4x3.svg/PNG/PDF, 4:3, 2 ноября 18:30; «Вектор», ул. Фрунзе, 60. Старые версии не удалять.
- Круглое меню: только названия команд и четыре SVG-иконки — этапы, заставка, отмена, подробное меню. Без стоимости, баллов, номеров команд и подписей. Раскрытие из точной области круга 64×64, закрытие и быстрое повторное открытие без гонки, reduced motion. В бумажном режиме название команды открывает ручной ввод баллов. Источники и печатные материалы — в подробных настройках.
- GitHub: отдельная ветка → commit → git push → PR. Без API blob. Слияние и публикация уже разрешены в переписке; повторное подтверждение не требуется. Сохранять текущую публичную аудиторию сайта.

Браузерные: tests/check-paper-browser.cjs, tests/check-cover-browser.cjs, tests/check-chronology-browser.cjs.
