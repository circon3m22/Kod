# Культурный код — последовательная редакция

Работать самостоятельно, без субагентов и генерации изображений: прямое пожелание пользователя. Новые инструкции пользователя имеют приоритет над прежними правилами сценария.

- Сайт автономный: index.html открывается без сборки, обязательного fetch, CDN и сервера. Локальные quiz-data.js, cover-art.js, cover-film.js, quiz-flow.js, app.js, styles.css и flow.css. Onest локальный, символы DejaVu. Сцена 1920×1080; в вертикальном окне CSS-поворот на 90°. Браузерная политика этой среды блокирует file://; не обходить ограничение и не утверждать, что прямой запуск проверен в браузере.
- Основной сценарий — state.current.screen='flow'; модель/контроллер в quiz-flow.js, порядок строится из данных. Афиша → правила → минутный таймер названий по клику → форма команд → 15 вопросов разминки → меню трёх этапов → шесть основных блоков → подсчёт → результаты первого этапа → творческое задание → капитаны → награждение. Клик, пробел и → ведут вперёд, ← назад; формы требуют корректного ввода. На первом входе правила, на повторном — сохранённая позиция.
- Правила: только заголовок по центру и три блока с прозрачными винтажными иллюстрациями: без телефонов, не подсматривать, 30 секунд на ответ. Источники/лицензии/хеши — source/rules-image-sources.json и credits.html. Цветные оригиналы не обесцвечивать; исходные ч/б оставлять ч/б.
- Новая игра: от 1 до 9 команд, непустые названия и разные номера 1–9. Номера редактируются в форме, порядок отображения по номеру. Старые сохранения/счёт/история сохраняются; команды сверх девяти не удалять автоматически — сначала редактор. Данные старого бумажного режима и legacyValue оставлены для совместимости.
- Разминка без таймера: слева вопрос, справа изображение, следующий клик — ответ. Никаких подписей к фото, номеров/стоимости или полос прогресса. Круглое меню или цифра 1–9 сразу присваивает 100 баллов выбранной команде. На вопрос один победитель; повторный выбор не дублирует баллы, смена команды переносит начисление, отмена возвращает прежнее состояние.
- После разминки только три карточки: основной этап, творческое задание, конкурс капитанов. Перед каждым основным блоком видны все шесть пронумерованных карточек; текущий блок выделен. В каждом 10 вопросов по 100…1000. Первый клик запускает 30 секунд, следующий клик во время отсчёта или ноль — следующий вопрос. Нажатие на маленькие часы — пауза/продолжение. После десятого вопроса автоматически 30 секунд на сдачу: только заголовок и часы, любой клик пропускает. Затем страница «Ответы блока», и для каждого задания вопрос → раскрытие ответа отдельным кликом. Между блоками следующая галерея, без заставок и таблиц результатов.
- Сохранены 75 заданий и их ID. По запросу 26 октября все десять вопросов «Что было раньше?» заменены: 41 карточка, 3–5 событий; исходники — source/chronology-before-20261026.json, проверка дат — source/chronology-review-20261026.json. Остальные исходные формулировки не менять без запроса. Для хронологии карточки событий сохраняются; раскрытие ставит их слева направо с датами, при одинаковом годе — с днём/месяцем. Картинки и alt есть у вопросов и ответов, видимые подписи не добавлять. Макеты длинных текстов и семи пар сопоставления имеют более широкую левую колонку.
- После шести блоков — «Подсчёт голосов». Круглая кнопка открывает бланки: отдельная команда, 6×10 галочек. Сохранять немедленно, обновлять баллы только разницей, не прибавлять весь бланк повторно. state.flow хранит base, warmWins, marks, manual и небольшие обратимые операции undo. Итог = прежний сохранённый счёт + разминка + отмеченные вопросы + ручные баллы. Проверять соответствие суммы и бланков при импорте; не выводить число правильных ответов из суммы баллов.
- После подсчёта единственная общая таблица — результаты первого этапа (разминка + основные блоки + сохранённая база). Творческое задание сохраняет подготовку 5 минут и защиту 3 минуты, затем ввод баллов каждой команде. Конкурс капитанов — прежний минутный конкурс и ручные баллы. Данных заданий капитанов нет, вопросы не выдумывать. После этих этапов таблиц результатов нет.
- Награждение: сначала титульная страница, затем по клику одна команда, от меньшего итогового счёта к большему. До тройки призёров место не подписывать. Для 3/2/1 — отдельное оформление, бронзовый/серебристый/золотистый акцент. При равенстве баллов место одинаковое (спортивная нумерация 1,1,3); номер команды используется только для стабильного порядка. После победителя оставаться на экране победителя.
- Таймер принадлежит конкретному шагу. При переходе/заставке/перезагрузке приостанавливать, старый дедлайн не должен переключать новый вопрос. Сохранение/загрузка включает номера, галочки, ручные баллы, отмену и позицию. Модель legacy остаётся для чтения старых файлов, основная навигация всегда через новый сценарий.
- Круглое меню: только названия команд и четыре иконки — этапы, заставка, отмена, подробное меню. Без счёта, стоимости и дополнительных подписей. На экране подсчёта сразу открываются бланки. Движение панели из 64×64 круга сохранено; отменять конкурирующие эффекты. Хостовые формы и подробное меню могут иметь необходимые подписи.
- Визуальная скорость 0.5×: MOTION_SCALE=2, CSS длительности/задержки удвоены. Игровые секунды не замедляются. Заставка — четыре кадра по 8 с К→О→Д→КОД, 8 с афиши, цикл 40 с. Вращение/смыкание/уменьшение/повторное увеличение каждой буквы идут одновременно. Между буквами прямой стык. Финальный КОД без вращения слегка смыкается/уменьшается; карта проявляется слева направо и уменьшается. Фото горизонтальны. Геометрия cover-art.js, доп. источники source/cover-film-sources.json. Исходная 4:3 афиша собрана из HTML/SVG, не растр.
- Оптимизация финала: девять секций, 27 заранее подготовленных текстур, карта растеризуется один раз. Буферы переиспользуются, подготовка по idle-задачам с таймерным запасным путём. Движение и прозрачность — Web Animations API на compositor; не возвращать покадровую перерисовку SVG-масок/карты или полноэкранный canvas-цикл. При уходе/уменьшении движения отменять подготовку и эффекты; по клику сначала зафиксировать текущий кадр. Переход через О — 2.56 с; карта исчезает за 760 мс, этапы проявляются слева направо.
- GitHub: ветка → commit → git push → PR, без API blob. Слияние и публикация уже разрешены, повторное подтверждение не нужно. Аудиторию сайта сохранять публичной.
- Пять новых смешанных портретов пока ждут 12 пользовательских исходников: source/mixed-portrait-plan.json, статус awaiting-user-portraits. План не подменяет действующие вопросы; последние два будущих задания смешивают трёх людей.

Проверки: node tests/check-sequence.cjs; node tests/check-sequence-browser.cjs; node tests/check-flow-layout.cjs; python3 tests/check-content.py; node tests/check-state.cjs; node tests/check-scoring.cjs; node tests/check-paper-flow.cjs; node --check app.js; node --check quiz-flow.js; git diff --check. Афиша: tests/check-cover-browser.cjs и tests/check-poster-film.cjs. Нативный замер производительности tests/measure-final-film.cjs запускать отдельно от других браузерных проверок. Старые tests/legacy относятся к прежним редакциям.

- Изображения между разными заданиями не повторять, включая ответы и карточки событий. Повтор внутри вопроса и его ответа допустим. Проверять SHA-256 всех используемых файлов; не обходить переименованием/обрезкой. Новые оригиналы и лицензии — source/question-refresh-image-sources.json. Полные даты в хронологии — по новому стилю; для нескольких событий одного года показывать день/месяц, даже если в задании есть другой год.
- На афише прежний CodeDisplay / Onest 500, «КУЛЬТУРНЫЙ» прописными, 112 px вместо прежних 93 px. В финальной сборке отдельная надпись проявляется compositor-анимацией opacity/transform; в К/О/Д скрыта, при клике/повторе отменяется. Крупные фото и маски не перерисовывать ради надписи.
- Логотип Молодёжного совета — assets/brand/youth-council-black.svg, только на афише и в основном меню трёх этапов; на выборе блоков и в самой игре не показывать; абсолютное позиционирование, не сдвигать карточки. Экспорт логотипа квиза: assets/brand/quiz-logo-black.svg и .png (3600×2160), белый фон, контурный Onest 500 и исходные секции КОД, чёрная заливка.

- Печатные бланки: design/answer-sheets.pdf, ровно один A4, сетка 2×3; шесть карточек 95×91 мм, поля страницы 8 мм, зазоры 4 мм, скругление около 3.2 мм, светлые сплошные контуры (opacity .18). Только два векторных логотипа, номер/название блока, вопросы 1–10 и строки ответов; без полей команды, баллов и пояснений. Генератор scripts/build-paper-printables.py вызывает build-cutout-sheets.py (PyMuPDF/fontTools/Inkscape), отдельный тест tests/check-printables.py. HTML-печать также должна давать один A4.
- Новый финал заставки: глобальный масштаб 1.48→1, разлёт секций .52, независимое закрытие букв с задержкой .12 логической секунды. Кривая quintic smootherstep даёт нулевую скорость/ускорение на концах; геометрия завершается к 3.65 логической секунды и совпадает с афишей. Все дорожки cached compositor и SVG-fallback используют одну кривую; первые три сцены и 8-секундная длительность финала сохранены.
