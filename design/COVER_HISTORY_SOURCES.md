# Исторические цветные фотографии для обложки

Пять подлинных ранних цветных фотографий Сергея Михайловича Прокудина-Горского. Цветные изображения получены совмещением исходных исторических цветоделённых негативов; это не современная раскраска чёрно-белых фотографий. Фотографии используются только для декоративной композиции обложки, созданной средствами HTML/CSS вручную. Генерация изображений не применялась.

Изображения загружены локально в assets/cover-history. Обложка работает без сети. Использованы уменьшенные копии Wikimedia Commons либо исходный файл, если он меньше стандартной уменьшенной копии; фактическая ширина файлов — до 1280 пикселей. Все файлы проверены декодированием. Полные метаданные, адреса загрузки и контрольные суммы — [cover-history-sources.json](../source/cover-history-sources.json).
