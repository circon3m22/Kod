# Культурный код

Исторический квиз для ведущего и проектора. Откройте index.html в современном браузере: сборка, сервер и интернет для игры не требуются. Все фотографии, шрифты и данные локальные. Рабочая сцена 1920×1080 масштабируется под окно; в портретном окне поворачивается на 90°.

После первого нажатия на афишу открываются правила с винтажными иллюстрациями, затем минута на выбор названий и форма регистрации. Можно добавить до девяти команд с разными номерами 1–9.

Разминка — 15 вопросов без таймера. Вопрос и изображение, по клику — ответ. Круглая кнопка открывает команды: выбранная команда сразу получает 100 баллов. Цифры 1–9 выбирают команду по присвоенному номеру. Повтор не дублирует начисление, выбор другой команды переносит баллы.

После разминки открывается меню трёх этапов. Основной этап содержит шесть блоков по десять вопросов, стоимость — от 100 до 1000. Перед каждым блоком видны все шесть пронумерованных карточек, текущий выделен. Клик запускает 30 секунд; следующий клик или истечение времени открывает следующий вопрос. После вопросов — 30 секунд на сдачу бланков, которые можно пропустить кликом. Затем титул «Ответы блока» и последовательный просмотр: исходный вопрос → правильный ответ по клику.

После всех блоков экран «Подсчёт голосов». Через круглую кнопку отметьте правильные ответы в отдельном бланке каждой команды: шесть строк по десять галочек. Баллы рассчитываются по стоимости вопросов и сохраняются сразу. Таблица результатов первого этапа складывает основной этап и разминку. Прежний импортированный счёт сохраняется как отдельная база.

Далее — творческое задание (5 минут подготовки, 3 минуты защиты) и ручные баллы каждой команде, затем минутный конкурс капитанов и ручные баллы. Условий капитанских заданий в исходных данных нет: этот конкурс ведёт ведущий. Общие результаты после этих двух этапов не показываются.

Награждение начинается отдельной заставкой. Каждый клик показывает следующую команду от меньшего счёта к большему. Места подписаны только для тройки призёров. При равных баллах команды делят место; показ заканчивается победителем.

Клик, пробел и → ведут вперёд, ← возвращает назад. На таймере первый клик запускает отсчёт. Маленькие часы вопроса позволяют поставить паузу. U отменяет последнее начисление, M открывает управление, F включает полный экран. В формах Enter подтверждает ввод. На заставке игра возобновляется с сохранённой позиции; таймеры при перезагрузке приостанавливаются.

Сценарий и подсчёт находятся в quiz-flow.js, оформление — flow.css. В app.js сохранены платформа, афиша, журнал, сохранение/загрузка и чтение прежних файлов. Все 75 вопросов сохранены в quiz-data.js; исходные формулировки и старые стоимости доступны в source/pre-paper-quiz-data.json и legacyValue.

Афиша 4:3 вручную собрана из HTML/SVG. Заставка: К → О → Д → КОД, по 8 секунд и 8 секунд афиши между повторами, полный цикл 40 секунд. Все визуальные анимации работают на скорости 0.5×, игровые отсчёты сохраняют свои секунды. Финальная сборка использует заранее подготовленные секции и compositor-анимации, без покадровой перерисовки большой карты и девяти SVG-масок.

Источники изображений и лицензии — credits.html и source/*.json. Три иллюстрации правил — CC0 с исходной прозрачностью, source/rules-image-sources.json. Печатные бланки и ключ ответов — design/answer-sheets.pdf и design/host-answer-key.html. Новые смешанные портреты ожидают пользовательских фотографий: source/mixed-portrait-plan.json.

Проверки: `node tests/check-sequence.cjs`, `node tests/check-sequence-browser.cjs`, `node tests/check-flow-layout.cjs`, `python3 tests/check-content.py`. Совместимость счёта/сохранений: `node tests/check-state.cjs`, `node tests/check-scoring.cjs`, `node tests/check-paper-flow.cjs`. Проверки афиши: tests/check-cover-browser.cjs и tests/check-poster-film.cjs. Для браузерных проверок нужен локальный HTTP-сервер и установленный Playwright/Chromium; блокировка file:// политикой данной среды не обходится.
