# Культурный код

Автономный исторический квиз для ответов на бумажных бланках: **15 вопросов разминки и 6 блоков по 10 вопросов**. Все 75 вопросов и ответов иллюстрированы. Подписей под фотографиями нет. Цветные оригиналы остаются цветными, архивные ч/б — ч/б.

Откройте `index.html` в распакованной папке. Интернет, сервер и сборка для игры не нужны. Данные и шрифты локальные.

Опубликованный сайт: https://cultural-code-quiz-tima-2026-a7.c49tv5dczr.chatgpt.site/

## Порядок игры

1. Нажмите на живую афишу. До первого раунда появятся три коротких правила с картинками: без телефонов, не подсматривать у других команд, 30 секунд на ответ в основных блоках. Правила показываются один раз на игру.
2. Разминка — **без таймера**: вопрос → клик → ответ → клик → следующий вопрос. Всего 15 вопросов, после последнего ответа — промежуточные результаты.
3. В основной части выберите один из шести блоков. Каждый вопрос появляется с остановленным таймером **00:30**. Первый клик, пробел, Enter или → запускает отсчёт. **Клик во время отсчёта сразу открывает следующий вопрос.** По нулю следующий вопрос открывается автоматически. Его таймер ждёт нового запуска. Нажатие на сами часы ставит отсчёт на паузу / продолжает его.
4. После последнего вопроса основного блока автоматически начинается **30 секунд на сдачу бланков**. По нулю открывается первый ответ. Все 10 правильных ответов идут по порядку, по клику. В хронологии карточки выстраиваются слева направо с годами; для событий одного года показаны также день и месяц.
5. После разминки «Продолжить» открывает шесть блоков. После каждого основного блока — заставка для ручной проверки. После завершения всех семи блоков автоматически открывается статистика.

Разминка: **100 баллов** за вопрос, максимум **1500**. В каждом основном блоке — вопросы от **100 до 1000 баллов**, максимум **5500**. Общий максимум — **34 500**. Вопросы располагаются по оценке сложности: первые проще, последние требуют специальных знаний. Гарантировать сложность для любой аудитории невозможно.

## Ведущему

Круг внизу открывает минимальное меню: названия команд и четыре иконки (этапы, заставка, отмена, подробное меню). В бумажном режиме нажатие на команду открывает ручное начисление. Цифры 1–9 **не выбирают победителя и не начисляют баллы** в бумажных вопросах.

При вводе баллов выберите блок, к которому относится проверенный бланк. Статистика показывает баллы каждой команды за разминку и шесть блоков, остальные корректировки и общий счёт. Отменённые операции исключаются. Изменения баллов вне блоков показываются в «Прочее». Статистика доступна также через подробное меню; она не пытается вычислять число правильных ответов по общей сумме.

M — подробное меню, U — отменить последнее начисление, F — полный экран, ← — предыдущий вопрос/ответ. Круг → три точки → «Следующий экран без ожидания» позволяет ведущему пропустить ожидание. Там же доступны пауза/сброс таймера, повторный запуск блока, команды, сохранение/загрузка JSON и необязательные творческий этап/конкурс капитанов.

При уходе с вопроса на заставку таймер приостанавливается. Блок продолжает показ с сохранённой позиции и остатком времени. После перезагрузки сначала открывается заставка, бумажный таймер приостановлен. Старые команды, счёт и история сохраняются; прежние стоимости сохранены в `legacyValue`.

## Дизайн и исходники

Живая афиша 4:3 собрана из HTML и SVG: девять разных исторических изображений внутри округлых букв КОД, круглая О, шрифт Onest. Заставка — **четыре цельных кадра по 4 секунды: К → О → Д → КОД**. Каждая буква непрерывно вращается, пока её крупные разнесённые части одновременно уменьшаются и смыкаются; затем собранная буква продолжает вращаться и снова увеличивается. Внутренних стадий нет, между буквами — прямые смены кадра. Части не перекрываются, фотографии остаются горизонтальными, мягко меняются и приближаются. Финальный КОД без вращения слегка смыкается и уменьшается с 116% до размера афиши. Его фон сначала белый: силуэт России постепенно проявляется мягкой волной слева направо и одновременно уменьшается с 3.6-кратного масштаба до своего места. Кадрирование финальных фото точно соответствует остановленным фото живой афиши. Между циклами афиша остаётся на 4 секунды; полный цикл — 20 секунд. Нажатие прерывает показ, карта исчезает за 380 мс, слово приближается через О, этапы проявляются слева направо. Уменьшение движения отключает сцены.

Контент: `quiz-data.js`. Новые факты и критерии: `source/paper-round-content.json`. Атрибуция новых изображений: `source/paper-image-sources.json`. Редакция до перехода на бланки: `source/pre-paper-quiz-data.json`; старые 12 вопросов разминки не потеряны. Все прежние 30 основных вопросов сохранены, изменены их стоимости и порядок. Повторная сборка данных: `python3 scripts/build-paper-rounds.py`; бланков: `python3 scripts/build-paper-printables.py`. Сборка не нужна для запуска.
