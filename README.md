# Культурный код

Исторический квиз для ведущего и проектора. Сайт состоит из локальных HTML, CSS, JavaScript, фотографий и шрифтов. Для игры без интернета распакуйте автономный архив целиком и откройте `index.html` в современном браузере.

На афише указано 2 ноября, 14:00. Перед стартом нажмите круг в углу и впишите число команд от 1 до 9. После правил и минуты на обсуждение названий каждая команда получает отдельный экран для ввода имени.

Разминка — 15 пар «вопрос → ответ» без таймера и баллов. Затем идут два этапа: основная часть и конкурс капитанов. Основная часть содержит шесть блоков по десять вопросов. Первый клик на вопросе запускает заметный 40-секундный таймер; следующий клик или окончание отсчёта открывает следующий вопрос. После каждого блока есть 30 секунд на сдачу бланков, затем вопросы и правильные ответы просматриваются по порядку.

Конкурс капитанов показывается отдельным экраном без таймера. После него ведущий вручную вводит баллы основной части каждой команды и выбирает одну команду, получающую ещё 1000 баллов. Итоги появляются только после этого выбора. Награждение показывает команды от меньшего итогового счёта к большему; нажатие после первого места возвращает в главное меню.

Круглое меню во время игры содержит только переход на главную, полный экран, сохранение, загрузку и новую игру. Игра автоматически сохраняется в браузере; для переноса между устройствами можно экспортировать и импортировать JSON. Бланки для печати находятся в `design/answer-sheets.pdf`: шесть прямоугольных карточек на одном листе A4. Ключ ведущего — `design/host-answer-key.html`.

Проверки сценария: `node tests/check-sequence.cjs`, `node tests/check-sequence-browser.cjs`, `node tests/check-flow-layout.cjs`. Проверки данных и сохранений: `python3 tests/check-content.py`, `python3 tests/check-printables.py`, `node tests/check-state.cjs`. Автономный архив: `python3 scripts/build-offline.py --output /tmp/kod-offline.zip`.
