# Культурный код

Минималистичная версия для участников квиза с цветными иллюстрациями. Главная собрана как живая афиша 4:3: отдельные надписи и слово «КОД» из девяти неповторяющихся исторических изображений Руси, войн, империи и СССР, вырезанных по цельным буквам. «О» строго круглая. При нажатии карта сразу плавно исчезает за 380 мс, текст затухает, слово «КОД» целиком приближается к центру буквы «О»; после этого карточки этапов плавно проявляются слева направо. 30 доступных вопросов основного поля в шести категориях, 12 вопросов разминки, бонус, таймеры, команды, история и сохранения. Исходные формулировки вопросов восстановлены, оставлены точечные исправления ошибок; исправления и источники перечислены в CONTENT_AUDIT.md, полные вопросы и ответы — в QUESTION_REVIEW.md. Исходные формулировки сохранены в данных.

## Новые категории

«Кадры прошлого» — пять фотозаданий: два кадра из фильмов и три исторических снимка. Видео не нужны. Шестая категория «Что было раньше?» показывает отдельную карточку с изображением для каждого события. На вопросе виден исходный порядок букв; при раскрытии карточки плавно становятся в правильный порядок слева направо, после чего появляются годы. Для событий одного 1961 года дополнительно показаны дни и месяцы. Для зачёта достаточно правильного порядка букв. Все 16 событий в пяти вопросах имеют иллюстрации. Стоимости обеих категорий: 200, 400, 600, 800, 1000. Полные условия, ответы, критерии зачёта, источники и атрибуция изображений — в [NEW_ROUNDS.md](NEW_ROUNDS.md).

Новые задания имеют отдельные идентификаторы; старые баллы сохраняются, отметки использованных видеовопросов не блокируют фотозадания. Прежние вопросы сохранены в source/replaced-video-questions.json.

## Шрифт

Onest подключён локально: Medium 500 для заголовков, Regular 400 для вопросов и интерфейса. Один вариативный файл содержит кириллицу и цифры; лицензия SIL OFL 1.1 — assets/fonts/Onest-OFL.txt. Стрелки и служебные значки используют локальный DejaVu Sans. Внешних шрифтовых сервисов нет.

## Афиша

Афиша строго **4:3**: белый фон со светлым силуэтом карты, круглое «О» и цельные силуэты «КОД» с тонкими внутренними швами. Девять разных изображений, без повторов; для Руси — репродукции исторических картин. Буквы КОД увеличены примерно на 15%, промежутки уменьшены с 90 до 35 единиц геометрии. «КУЛЬТУРНЫЙ» набрано прежним Onest Medium; «Исторический квиз», дата и адрес увеличены. Формы и торцы фотосекций скруглены. Над словом — «КУЛЬТУРНЫЙ» и «Исторический квиз». **2 ноября 18:30 · «Вектор», ул. Фрунзе, 60**.

- [PNG 3200 × 2400](design/cultural-code-poster-kod-4x3.png) — для публикации.
- [PDF 400 × 300 мм](design/cultural-code-poster-kod-4x3.pdf) — для печати.
- [Самостоятельный SVG](design/cultural-code-poster-kod-4x3.svg) — встроенные фото и текст в кривых.

На сайте композиция собрана из HTML и SVG, без готовой картинки афиши. По серому силуэту карты проходит мягкий белый блик с циклом 22 секунды, ограниченный исходной векторной маской; цикл бесшовный. Фотосекции — отдельные элементы: на заставке фото непрерывно смещаются под неподвижными масками с разными скоростями и фазами, без скачков на стыке цикла. При нажатии движение фото замирает, карта исчезает за 380 мс, КОД приближается через О. Параллакс, приближение и появление этапов учитывают системное и внутреннее уменьшение анимаций. Данные букв и фотографий общие для сайта и печатной афиши: cover-art.js, сборка — scripts/build-cover-art.py. Источники текущей версии: source/cover-era-sources.json. Фон живой и печатной афиши — светлый векторный силуэт карты без подписей и внутренних границ, assets/design/poster-russia-silhouette.svg (Natural Earth и OpenStreetMap / geoBoundaries); сведения об источнике и выбранном контуре — source/poster-background-source.json. Контур построен в проекции Альберса из source/russia-silhouette-geodata.geojson; равномерное масштабирование, без обводки и растягивания. Скрипт сборки — scripts/build-map-silhouette.py (только для пересборки: shapely, pyproj); запуск игры новых зависимостей не требует. Акварельный вариант отменён, исходный файл сохранён в репозитории. Полная атрибуция встроена в метаданные экспортов и сохранена в design/cultural-code-poster-kod-4x3-credits.txt; исходные лицензии фотосекций сохраняются. Прежние версии афиши сохранены.

## Открыть

Распакуйте архив целиком, откройте папку cultural-code и файл index.html. Для работы не нужны интернет, сервер, сборка или установка программ. Скопируйте всю папку на флешку. Не открывайте HTML внутри ZIP.

Опубликованная версия: https://cultural-code-quiz-tima-2026-a7.c49tv5dczr.chatgpt.site/ . Офлайн-версия не требует входа.

## Обычные экраны

- Нажатие в любом месте главной запускает затухание текста и приближение в центр «О»; после завершения карточки этапов появляются слева направо. Если команд ещё нет, создаются две; названия и состав меняются через круг → «···» → «Команды».
- Вначале предложены две команды. Нажмите на название для редактирования. Круг «+» добавляет команду, «×» удаляет после подтверждения, стрелка открывает этапы.
- Этапы показаны четырьмя высокими карточками в одну строку слева направо: разминка, основная часть, творческое задание, капитаны. Внизу каждой карточки — цветной предмет без фона; стрелок, номеров и подзаголовков нет. Результатов в списке нет.
- В разминке первое нажатие показывает ответ, следующее открывает очередной вопрос. После последнего ответа открываются промежуточные итоги, затем — игровое поле.
- В таблице нажмите на стоимость вопроса. Первое нажатие на текст или изображение вопроса раскрывает ответ, следующее возвращает к таблице и помечает вопрос использованным.
- Увеличение изображений доступно через круг → «···» → «Увеличить материалы». Изображение на вопросе и ответе продолжает показ, как и нажатие на текст. Прокрутка длинного текста не должна переключать вопрос.
- На бонусном и капитанском экранах нажатие на часы запускает или приостанавливает таймер. Фазы подготовки и защиты выбираются в панели ведущего.

На экранах для участников нет шапки, постоянного счёта, номеров исходных слайдов, служебных инструкций и кнопок ответа. Изображения показываются в своих исходных цветах; архивные чёрно-белые кадры не раскрашиваются. Обложка использует согласованную приглушённую цветную палитру. Неактивные и использованные ячейки показаны тире.

### Переходы и результаты

После разминки, основной части и творческого задания показываются промежуточные итоги. «Продолжить» или → открывает следующий этап. Основная часть завершается автоматически после последней доступной ячейки; ведущий также может завершить её раньше кнопкой «Продолжить» в полной панели или клавишей → на игровом поле. Творческое задание и конкурс капитанов завершаются таким же действием ведущего.

После капитанов открывается меню этапов без автоматического показа итоговой таблицы. Для итоговых результатов откройте круг → «···» → «Финал». Эта возможность доступна и в середине игры. Цифры выбирают команду: баллы начисляются один раз при завершении задания. Начисление за текущий вопрос через полную панель также отмечает его оценённым; отдельное ручное изменение счёта остаётся доступно.

Ссылка «Источники фото» в полной панели → «Настройки» открывает credits.html. Фотографии обложки не генерировались; происхождение описано в design/COVER_HISTORY_SOURCES.md.

## Изображения ответов

У каждого из 42 ответов (30 основных + 12 разминки) есть иллюстрация с подписью. Современные фотографии и художественные образы обозначены явно. Картинки ответов появляются только после раскрытия; условия и формулировки не менялись. Для Ялты 1945 использован подлинный Kodachrome, для Парада Победы — кадр цветной кинохроники 1945 года. Новые изображения хранятся локально в assets/answer-history, атрибуция и контрольные суммы — source/answer-image-sources.json и credits.html. Архивные ч/б снимки и кадры ч/б фильмов сохранены без раскрашивания.

## Незаметное начисление баллов

Цифры 1–9 на физической клавиатуре **выбирают команду**, не меняя счёт. Например, нажатия 1, 1, 2 оставляют выбранной только вторую команду. Номер примерно на секунду появляется в нижнем круге с мягкой анимацией. В меню круга выбранная команда выделена плашкой и точкой. Снятие выбора доступно под тремя точками в полной панели. Пояснения доступны скринридеру, видимых служебных текстов нет.

**Баллы начисляются один раз, только при завершении текущего задания и переходе дальше:** после ответа в основном раунде — при возврате к таблице; в разминке — при переходе к следующему вопросу. Раскрытие или скрытие ответа, повторные нажатия, увеличение изображения и открытие меню не начисляют баллы. Уход назад или в меню этапов отменяет неподтверждённый выбор. Без выбранной команды вопрос завершается без начисления. Удержание клавиши не меняет выбор повторно.

Стоимость: разминка — 10, основной вопрос — его стоимость, бонус — 200, капитаны — 100. Для бонуса и капитанов переход дальше выполняется кнопкой «Продолжить» в полной панели или клавишей →. На обложке, выборе команд, меню этапов и игровом поле цифровой выбор отключён.

Повторное открытие уже оценённого задания не позволяет начислить баллы ещё раз цифровой клавишей или строкой команды. U отменяет последнюю фактическую операцию начисления; после её отмены задание можно оценить снова. Намеренные корректировки, начисления нескольким командам и штрафы остаются доступны в полной панели ведущего. Прежняя история сохранений учитывается при защите от повторного начисления.

На телефоне нажмите небольшой круг в правом нижнем углу. Нажатие на команду выбирает её и закрывает меню. В компактном меню — только названия команд и четыре иконки: домик открывает этапы, заставка — афишу, отмена возвращает последнее начисление, три точки открывают полную панель. Числа, стоимость и подписи скрыты. Панель плавно вырастает из круглой кнопки и сворачивается в неё; нажатие снаружи или Escape закрывает меню. Цифровая клавиатура, увеличение материалов и снятие выбора доступны под тремя точками в разделе «Этапы». Ввод 1–9 меняет выбранную команду, поле очищается. Для команд с номерами больше 9 используйте строки списка. Выбор сохраняется вместе с текущим заданием, в том числе при экспорте в JSON.

В таймерах изменяющиеся цифры прокручиваются снизу вверх, каждый разряд отдельно; двоеточие и неизменившиеся цифры остаются на месте. Прокрутка работает и на границе минут. В последние 10 секунд сохраняется небольшая монохромная пульсация. Настройка «Уменьшить анимации» и системная prefers-reduced-motion отключают движение.

Меню и экранная клавиатура видны на том же экране. Если телефон или компьютер зеркалируется на проектор, полностью скрыть открытое меню невозможно. Для начисления без раскрытия меню используйте физическую клавиатуру. Отдельный синхронизированный пульт на другом устройстве в этой версии не реализован.

## Полная панель ведущего

Круг → «···» или M открывает управление этапами, командами, баллами, историей, таймерами, восстановлением вопросов и сохранениями. Кнопки «Назад» и «Продолжить» находятся в полной панели; значок домика в компактном меню возвращает к этапам. Сброс игры и удаление команды требуют подтверждения.

| Клавиша | Действие |
| --- | --- |
| 1–9 | Выбрать / изменить команду для начисления при переходе дальше |
| U | Отменить последнее начисление |
| Space | Показать / скрыть ответ |
| Enter / → | Продолжить показ |
| ← | Назад, в разминке к предыдущему вопросу |
| Esc | Закрыть панель или вернуться назад |
| M | Полная панель ведущего |
| F | Полный экран при поддержке браузером |

На обычных кнопках Enter и Space сохраняют стандартное действие кнопки. Горячие клавиши не перехватывают ввод в полях.

## Сохранения

Автосохранение использует localStorage, когда браузер разрешает его. Сохраняются команды, баллы, история, статусы вопросов, текущий этап, открытый ответ, настройки и таймеры. Прежние JSON-сохранения совместимы. Обложка при открытии не сбрасывает результаты. В полной панели можно экспортировать сессию в JSON, импортировать файл либо вставить его текст через резервный импорт.

При file:// доступность localStorage зависит от браузера и пути. Перед мероприятием, переносом папки и после важных раундов сохраняйте JSON в файл. Перенос папки не переносит хранилище браузера. Максимум 24 команды, 10 000 записей истории, JSON до 5 МБ. Максимальный счёт команды ±1 000 000 000. Баллы не передаются на сервер.

## Сцена

Виртуальный размер всегда 1920×1080. Сцена вписывается с полями, без обрезки и прокрутки страницы. Вертикальное окно поворачивает композицию на 90° через CSS. При горизонтальном положении дополнительного поворота нет. Учитываются visualViewport и безопасные отступы. Клавиатура телефона не должна менять выбранную ориентацию сцены.

Fullscreen API и блокировка системной ориентации зависят от браузера. Отказ не мешает работе. На iPhone открывайте опубликованный сайт в Safari: встроенный просмотр HTML в «Файлах» может не запускать JavaScript. CSS-поворот не меняет ориентацию операционной системы.

## Данные и исходники

Фактически предоставлены «квиз код1(2).ppt» и «сценарий квиза (1).docx». Оригинальная презентация сохранена без изменений внутри source/kviz-original.ppt.zip (распакуйте её при необходимости), сценарий — source/scenario.docx. Конвертация LibreOffice находится в source/kviz-converted.pptx. source/slides-extracted.json содержит извлечённые тексты всех 52 слайдов, таблицу ссылок, изображения и сведения о фигурах. source/scenario-extracted.txt содержит полный текст сценария.

quiz-data.js подключается обычным script, без fetch и ES-модулей. Вопросы независимы от компонентов интерфейса. Основные поля: id, category, value, type, text, answer, images, answerImages, video, enabled, status, sourceSlide, answerSlide, pairEvidence. Два задания matching имеют columns и matches (индексы с нуля), перенесённые по стрелкам исходного ответа.

Для добавления вопроса сохраните уникальный id и одну из существующих пар category/value. Если вы добавляете категорию или стоимость, расширьте categories/values. Количество строк и числовых столбцов сетки определяется этими массивами; читаемость нужно проверить отдельно. Для блица заполните массив captains объектами с уникальным id, text, answer, images и answerImages. Не добавляйте неподтверждённые исторические материалы.

Скрипт scripts/extract-assets.py повторяет извлечение медиа и текстов. Для него нужны Python, python-pptx и python-docx, только при разработке. Он не перезаписывает проверенную игровую базу quiz-data.js.

## Бесплатный статический хостинг

Это обычный статический сайт, подходящий для GitHub Pages и Cloudflare Pages. Сборка не нужна. Для публикации достаточно четырёх файлов приложения и папки assets. Исходники мероприятия можно оставить только в локальном архиве.

GitHub Pages: поместите файлы в корень репозитория; включите публикацию Pages из ветки и корневой папки. Файл .nojekyll включён. После публикации откройте выданный платформой адрес. Точный интерфейс настройки сервиса может меняться.
