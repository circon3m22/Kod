# Исходные материалы

`kviz-original.ppt.zip` содержит оригинальный `kviz-original.ppt` без изменений. Архив позволяет перенести файл через ограничение размера запроса; это не замена исходника.

Распакуйте стандартным архиватором либо из корня проекта:

```sh
python3 -m zipfile -e source/kviz-original.ppt.zip source
```

Конвертированная презентация `kviz-converted.pptx` уже распакована и доступна для анализа. Для запуска самого квиза архив распаковывать не требуется.
